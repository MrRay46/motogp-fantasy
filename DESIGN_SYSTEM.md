# 🎨 RayonGrid Design System v1.0

Última actualización: Julio 2026

---

# Filosofía

RayonGrid no busca ser únicamente un Fantasy de MotoGP.

Nuestro objetivo es construir una aplicación moderna, elegante y muy cuidada visualmente, donde cada detalle transmita calidad.

La prioridad siempre será:

1. Simplicidad.
2. Claridad.
3. Rapidez.
4. Elegancia.

Geist

Estilo:

• Mucho espacio.

# Botones

## Primario

Color naranja.

Es el botón de acción principal.

Solo debe existir uno por pantalla.

## Secundario

Borde gris.

Sin fondo.

---

# Cards

Todas las tarjetas deben compartir:

- Fondo oscuro.
- Bordes redondeados.
- Borde muy sutil.
- Animación hover ligera.

---

# Espaciado

Toda la interfaz debe respirar.

Nunca saturar la pantalla.

Priorizar espacios amplios antes que añadir más contenido.

---

# Iconografía

Librería oficial:

Lucide React.

No utilizar emojis como solución definitiva.

Los emojis solo podrán utilizarse durante fases de desarrollo.

---

# Animaciones

Todas las animaciones deben ser:

Suaves.

Rápidas.

Naturales.

Evitar efectos exagerados.

Inspiración:

Apple

Linear

PlayStation

MotoGP

---

# Responsive

Diseñar siempre primero para móvil.

Después adaptar a escritorio.

Nunca al revés.

---

# Filosofía de desarrollo

Antes de añadir una nueva funcionalidad debemos preguntarnos:

¿Hace la aplicación más útil?

¿Hace la aplicación más sencilla?

¿Hace RayonGrid más profesional?

Si la respuesta es NO, la funcionalidad debe replantearse.

---

# Objetivo

Cuando un usuario abra RayonGrid queremos que piense:
